Download ARES.exeWindows, one file: Windows 10 or 11, 64-bit: one file to run, 14.9 MB
Download ARES-windows.zipWindows, a folder: the same as a folder, with the example programs beside it, 14.7 MB

ARES-linux-x86_64.tar.gzLinux: coming soon

Option A: Windows, one file. Put ARES.exe anywhere, the desktop for one, and double-click it. The first time, in the SmartScreen message, choose More info > Run anyway.

Option B: Windows, a folder. Unzip ARES-windows.zip where you like, then double-click ARES.exe in the folder; the example programs are beside it. The first time, Windows asks as it does for the one file.

Option C: macOS, Apple Silicon. Unzip the file and open ARES once, then choose Open Anyway in System Settings > Privacy & Security (on macOS 12: System Preferences > Security & Privacy).

Option D: from the source code, with Python. Install Python 3.11 or newer. In a copy of the source code run these commands, then run ARES with the command .venv/bin/python -m ares. On Windows write py for python3 and .venv\Scripts\python for .venv/bin/python. Building from source also makes the packages.

python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python tools/fetch_toolchain.py

ARES runs on Windows 10 or 11 (64-bit) and on macOS 12 or newer on Apple Silicon. The GNU assembler and linker come with it: nothing else needs to be installed. From the source code it needs Python 3.11 or newer (on Linux 3.12 or newer, with python3-tk).

All releases, with the source code of the GNU assembler and linker and of Unicorn that ARES includes.
