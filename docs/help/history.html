ARES - ARM Educational Simulator

Release 1.0

November 2026

Release history

ARES 1.0 was released in November 2026. It is the first release. First used in the EEL 3801 Computer Organization labs at the University of Central Florida. It contains:

  • The editor, with several open files, syntax colours, find and replace, and the capital-letters rule (Edit > Capitalize Instructions).
  • The GNU assembler and linker of the Arm GNU Toolchain 14.2.Rel1, the processor and memory of Unicorn 2.1.4, and the disassembler Capstone 5.0.9.
  • Run, step, backstep, pause, stop and reset, breakpoints, a run speed, and the registers, floating-point registers, memory and labels.
  • The system calls of the Syscalls page, and the DE1-SoC computer's JTAG UART.
  • Nine tools: ARM X-Ray, BHT Simulator, Bitmap Display, Data Cache Simulator, Digital Lab Sim, Dynamic Instruction Counter, Floating Point Representation, Keyboard and Display MMIO Simulator, Memory Reference Visualization; and the Memory Map.
  • The Help, with every instruction, pseudo-instruction and system call, the directives, and example programs under File > Open Example.
  • Packages on GitHub: ARES.exe, ARES-windows.zip, ARES-macos-arm64.zip.
