The window and the editor

The window

  • Edit: your files, one tab each. Keywords are coloured as you type.
  • Execute: the Text Segment (each instruction with its address, code and source line), the Data Segment (memory, eight words a row) and, with Settings > Show Labels Window, the Labels.
  • Registers, Coproc 10 and Coproc 11: the registers (see the Registers tab under ARM).
  • ARES Messages: what the assembler and the commands report.
  • Run I/O: what the program prints, and where it reads what you type.

The title bar shows the file on top, with * after its name while it has changes that are not saved, and the version: hello.s* - ARES 1.0. The dividers between the parts can be dragged and the window resized, for as long as ARES runs: every start opens maximized, with the default layout. A scroll bar shows only while what it scrolls does not fit; the editor always has both. The toolbar holds the commands used most, in the order of the menus: New, Open, Save, Save As, Undo, Redo, Cut, Copy, Paste, Find/Replace, Assemble, Go, Step, Backstep, Pause, Stop, Reset and Help. Rest the mouse on a button to read what it does. A gray button or menu item is not available at the moment. At the right of the toolbar the Run speed slider sets how fast Go runs (see the Debugging tab).

The editor

  • File > New opens a new file, File > Open an existing one, and each has a tab with a close button. File > Open Example opens a copy of one of the programs that come with ARES, as a new file with the example's name that is not saved yet; File > Save then asks where to save it. ARES asks before it closes a file with changes that are not saved, also at File > Exit.
  • Under the text the status line shows Line: x Column: y, and Show Line Numbers turns the numbers at the left on and off.
  • Edit has Undo, Redo, Cut, Copy, Paste and Select All. Edit > Find/Replace finds and replaces text, with Match case and Whole word, one at a time or all at once. There, Return presses the button that has the focus, else Find.
  • A new line starts as far in as the line above it. The Tab key inserts spaces, or a tab with Settings > Editor Font.
  • The colours are CPUlator's: registers blue, numbers green, labels being defined dark green and bold, directives teal, comments brown and strings dark red.

Assembling

Run > Assemble (F3) assembles the file on top with the GNU assembler. ARES Messages shows what happens, and each error or warning as Error in hello.s line 7: ..., with a red mark at the left of the line until the next Assemble. A click on the message selects the line in the editor.

A program with no _start is a warning, not an error: it starts at address 0x00000000.

After an Assemble without errors ARES shows the Execute tab. Opening a file or going to another file's tab changes nothing there: only Assemble loads a program. Closing the file of the assembled program unloads it, and ARES goes back to the state it has at the start, keeping the text of ARES Messages and Run I/O.

File > Dump Memory saves the program's code or data to a file, as binary or as hexadecimal text.

Input

When the program reads input (for example with SVC #5), Run I/O comes to the front with a blinking text cursor: type the line and press Enter. At other times ARES Messages and Run I/O show no text cursor; their text can still be selected with the mouse and copied with Ctrl+C. With Settings > Popup Dialog for Input on, a small dialog asks for the line instead.

Capital letters

With Settings > Require Capital Letters on, as it is at first, ARES refuses a program whose instructions or registers are not in capitals, and shows each line corrected. Directives are in lowercase. Edit > Capitalize Instructions corrects the whole file. Comments and strings are not checked, and labels can be spelled in any way, as long as it is always the same.
