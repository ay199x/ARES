Introduction

MARS made MIPS assembly easy to learn, with an editor, a debugger and tools in one program, but ARM had nothing like it. The closest was CPUlator, which beginners in assembly language find hard to learn.

So ARES was built: an easy simulator for ARMv7 that university labs can use. Its first version is used in the EEL 3801 labs at UCF.

Fun fact: ARES stands for ARM Educational Simulator, and Ares is the Greek name of the god of war whom the Romans called Mars, so ARES and MARS mean the same thing in two languages.

What ARES is

ARES, the ARM Educational Simulator, runs programs in ARMv7 assembly language on a simulated DE1-SoC computer. It supports the ARMv7 instruction set, with the same assembler and options as CPUlator's ARMv7 DE1-SoC system, so programs written for CPUlator assemble here too, once they are in capitals (see the IDE tab). ARES simulates no interrupts or timers.

A first program

Choose File > New and type this program. In ARES a program starts with its data, then .global _start and .text, and instructions and registers are written in capitals.

        .data
hello:  .asciz  "Hello, world!\n"

        .global _start
        .text
_start: LDR     R0, =hello      @ R0 = the address of the text
        SVC     #4              @ print the string
        SVC     #10             @ end the program

Assemble and run

  • Save the file with File > Save (Ctrl+S).
  • Press F3 (Run > Assemble). Errors appear in ARES Messages, each with its file and line: click one to go to the line. Without errors ARES shows the Execute tab.
  • Press F5 (Go). The text appears in Run I/O, followed by -- program is finished running --.
  • Press F12 (Reset) to start again.

Where to read on

The ARM tab of the Help window is about the language: every instruction, the directives, the system calls, the registers and the memory. Its ARES tab is about the program: IDE for the window, Debugging for going through a program, Settings, Tools, Keyboard shortcuts, and Limits for what ARES does not do.

Example programs

File > Open Example lists the short programs that come with ARES, among them one for most of the tools. Choosing one opens a copy as a new file that is not saved yet: run it, change it, and save it where you like. The example itself stays as it is.
