Settings

The Settings menu keeps its choices from one time to the next, for each user of the computer. They are kept in the file settings.json in the folder ARES of the user's application data, with the last folder used. The window's size and dividers are not kept.

SettingAt firstWhat it does
Show Labels Windowoffshows the Labels beside the Text Segment and the Data Segment
Assemble File Upon Openingoffassembles a file as soon as it is opened
Addresses in Hexadecimalonshows addresses in hexadecimal, else in decimal
Values in Hexadecimalonshows the values of registers and memory in hexadecimal, else in decimal
Require Capital Lettersonrefuses a program whose instructions or registers are not in capitals
Popup Dialog for Inputoffasks for typed input in a small dialog, not in Run I/O
Enable Backstep While Runningoffkeeps the history of a run at full speed, which makes it slower

Editor Font opens a dialog with the font and the size of the editor, the Tab width, and Tab key inserts spaces, which is on at first. Show Line Numbers, under the editor, is kept too.

Restore Defaults puts all of this back as it was at first, except the last folder used.
