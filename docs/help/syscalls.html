System calls

A program asks ARES for a service with SVC #N, where N is the service's number. Arguments go in R0 to R3, floating-point ones in S0 or D0, and results come back in the registers listed. Every other register keeps its value, and so do the flags.

Notes

  • Output formats: 1 prints a signed number, 36 an unsigned one, 34 0x and eight lowercase hexadecimal digits, and 35 thirty-two binary digits.
  • 8 reads at most R1 - 1 characters, keeps the end of the line if it fits, and ends with a zero byte.
  • File descriptors 0, 1 and 2 are Run I/O's input, output and error output.
  • Status of the input dialogs: 0 OK, -1 not a number, -2 cancelled, -3 OK with no input; 54 gives -4 when the text was cut to fit.
  • 31 and 33 play no sound: ARES has no synthesizer. 33 still waits for the note's duration.
  • An unknown number ends the program with a runtime error.
