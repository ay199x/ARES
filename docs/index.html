ARES (ARM Educational Simulator)

An IDE for ARMv7 Assembly Language Programming

ARES is a lightweight interactive development environment (IDE) for programming in ARMv7 assembly language, intended for students and teachers of computer organization. It assembles programs written for CPUlator's ARMv7 DE1-SoC system with the same GNU assembler, once their instructions and registers are in capitals (Edit > Capitalize Instructions does that), and simulates the DE1-SoC computer they run on, with its JTAG UART, LEDs, switches and seven-segment displays.

ARES features overview:

  • A window you work with the mouse, with an editor built in
  • The GNU assembler and linker included: nothing else to install
  • Registers you edit in place, like the cells of a spreadsheet, and a view of memory
  • Values shown in hexadecimal or in decimal
  • Floating-point registers, and a bit-by-bit view of 32-bit floating-point numbers
  • Runs at a speed you choose, one instruction at a time, and backwards
  • System calls for text and number input and output, files and dialogs
  • Teaching tools in their own windows, such as the ARM X-Ray datapath animation and a data cache simulator
